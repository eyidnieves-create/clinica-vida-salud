# Sistema de Gestión de Citas Médicas — Clínica Vida Salud

## Descripción
Sistema web desarrollado para apoyar la gestión de pacientes y citas médicas de la Clínica Vida Salud.

## Tecnologías utilizadas
- PHP
- PostgreSQL
- Supabase
- HTML y CSS
- XAMPP para el entorno de desarrollo local

## Funcionalidades implementadas
- Inicio de sesión y control de acceso.
- Gestión de pacientes.
- Registro y consulta de citas médicas.

## Estructura del proyecto
El código fuente está organizado en archivos PHP y una carpeta de configuración para la conexión con la base de datos.

## Instalación
1. Instalar XAMPP con soporte para PHP.
2. Colocar el proyecto en la carpeta `htdocs`.
3. Configurar las credenciales de conexión en el archivo de configuración local.
4. Configurar la base de datos en Supabase.
5. Abrir el proyecto desde el navegador.

## Seguridad
Las credenciales de conexión deben configurarse localmente y no publicarse en el repositorio.
